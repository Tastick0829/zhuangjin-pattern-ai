# 数据集说明

> **数据集图片本身不随仓库分发**（原因见文末「为什么不分发」）。本文件说明数据集的构成、构建流程、以及你如何自行准备一份等价的数据集。

---

## 一、数据集构成

原始数据集**约 172 个文件 / 294 MB**，按用途分为几个子集：

| 子集 | 文件数 | 体积 | 用途 |
| --- | --- | --- | --- |
| `birme-512x512/` | 18 | 3.96 MB | **训练集**：已用 BIRME 批量预处理为 512×512 |
| `壮锦纹样图案/` | 47 | 87.33 MB | 高分辨率纹样原图（素材库） |
| `壮锦纹样/` | 8 | 24.44 MB | 纹样分类整理 |
| `部分/` | 22 | 12.94 MB | 阶段性素材 |
| `纹样/` | 7 | 3.24 MB | 纹样小样 |
| `壮锦/` | 3 | 0.02 MB | 早期素材 |
| `参考/` | 7 | 25.72 MB | 第三方参考文献（PDF，未分发） |
| 根层散图 | ~50 | ~20 MB | Liblib 生成产物（64 位 hex 命名）与 `output (N).png` |

> 根层的 64 位 hex 命名文件是 **Liblib 平台的生成结果**（平台用内容哈希命名），`output (N).png` 是本地导出。这些是**产出**而非**训练素材**，保留用于结果展示。

## 二、数据预处理流程

```text
① 采集整理          收集壮锦纹样图片，人工筛选（去重、去水印图、去模糊）
       │
② 尺寸统一          BIRME 批量缩放到 512×512
       │                （BIRME - Bulk Image Resizing Made Easy）
       │                为什么是 512：与 LoRA 训练分辨率、推理分辨率三者统一
       │
③ 配对打标          每张图配一个同名 .txt，内容为英文 caption
       │                （12 份打标文件完全同构，见下）
       │
④ 目录组织          train/aki/xxx.png + train/aki/xxx.txt
                        ↓
                  供 kohya-ss/sd-scripts 读取（train_data_dir = "./train/aki"）
```

### 关于步骤 ② 的两个细节

**为什么必须统一尺寸**：训练配置里 `resolution = "512,512"` 是对**短边**的处理约定。若原图尺寸参差不齐，训练框架会在每个 batch 内做缩放，导致实际学习的分辨率不稳定。

**为什么不用 `enable_bucket`**：训练参数里 `enable_bucket = false`——本数据集已统一尺寸，不需要分桶（分桶是为多分辨率混合训练设计的）。

## 三、打标规范

### 3.1 实际使用的 caption

`prompts/captions/` 下 12 份 `.txt` 内容**完全一致**，均为单行英文 tag 串：

```text
no humans, intangible cultural heritage, Zhuang brocade, geometric patterns,
traditional patterns, ethnic style, colorful decoration, fabric patterns,
Pattern, Colorful, Zhuang ethnic traditional pattern style
```

### 3.2 拆解每一段的用意

| 标签段 | 作用 |
| --- | --- |
| `no humans` | **负向排除**：壮锦纹样是纯图案，训练时要明确"不含人物" |
| `intangible cultural heritage` | 文化属性定位（非遗） |
| `Zhuang brocade` | **核心主体**：壮锦（英文标准名） |
| `geometric patterns` | 关键视觉特征：几何纹样 |
| `traditional patterns` | 传统纹样归属 |
| `ethnic style` | 民族风格 |
| `colorful decoration` | 色彩特征：多彩装饰 |
| `fabric patterns` | 材质语境：织物纹样 |
| `Pattern, Colorful` | **重复强调**（大小写变体，增强权重） |
| `Zhuang ethnic traditional pattern style` | 综合风格描述（长的组合句式，T5 编码器擅长） |

### 3.3 打标策略的关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| **语言** | 英文 | Flux 的 T5 编码器在英文上训练最充分；且 `prompts/captions` 与推理提示词同语言，避免跨语言语义漂移 |
| **粒度** | **泛化标签**（不逐图描述具体构图） | 打标过细 → 模型只会复现训练集那几张图；泛化标签 → 学到"什么是壮锦风格" |
| **12 份内容一致** | 是 | 数据集内的纹样风格高度同质，逐图差异化打标的意义不大（**但如果做数据集扩充，应改为差异化打标**） |
| **不洗牌**（`shuffle_caption = false`） | 是 | 所有 caption 相同，洗牌无意义 |
| **不加触发词** | — | 12 份里有 11 份内容是模板；若要用触发词应全量统一添加，当前未采用 |

### 3.4 与推理提示词的关系

**训练打标 ≠ 推理提示词**，两者的目标相反：

| | 训练 caption | 推理 prompt |
| --- | --- | --- |
| 目标 | 覆盖**共性**（让模型学会"什么算壮锦"） | 约束**个性**（指定构图、配色、母题） |
| 粒度 | 泛化 | 具体 |
| 长度 | 短（关键词堆叠） | 长（自然语言描述） |

推理提示词见 [`04-workflow.md`](./04-workflow.md)。

## 四、如何自行准备等价数据集

### 4.1 数据来源建议

| 途径 | 说明 | 注意 |
| --- | --- | --- |
| 博物馆 / 文化馆公开资料 | 广西民族博物馆、广西非遗保护中心等 | 确认素材授权范围 |
| 非遗数据库 | 国家级非遗代表性项目数字资源 | 多为**研究用途**授权，商用需另议 |
| 公开学术论文附图 | 但**版权归原作者** | 仅可作参考，不宜直接入训练集 |
| 自行拍摄实物 | 授权范围内拍摄的壮锦实物 | 最干净的来源 |
| 开源数据集 | 检索是否有已授权的民族纹样数据集 | 核对许可协议 |

### 4.2 规模建议

| 规模 | 适用 |
| --- | --- |
| < 20 张 | 仅够验证流程（本项目训练集是 18 张级别） |
| 50–100 张 | 风格开始稳定 |
| 200+ 张 | 风格表达较充分 |

> 本项目数据集规模偏小，配合 `network_dim = 2`（低容量）来抑制过拟合。这是小数据量下的合理配置。

### 4.3 目录结构（供训练脚本读取）

```text
train/
└── aki/
    ├── 001.png
    ├── 001.txt        # 内容取自 prompts/captions/
    ├── 002.png
    ├── 002.txt
    └── ...
```

对应训练配置里的 `train_data_dir = "./train/aki"` 与 `caption_extension = ".txt"`。

## 五、为什么数据集不分发

三个原因，都很实际：

### 1. 体积

原始数据集 294 MB（其中「壮锦纹样图案」单个子集就 87 MB）。全部塞进 Git 仓库会让 clone 变得很痛苦，且 GitHub 对单文件与仓库体积都有约束。

### 2. 版权与授权不明

壮锦纹样图片的**著作权状态复杂**：

- 实物拍摄图 → 摄影者享有著作权
- 博物馆藏品的数字化图像 → 馆方可能有专门规定
- 从第三方渠道获取的图 → 授权链条往往无法追溯

**没有明确授权就公开分发，是有法律风险的行为。** 不能因为"是传统文化元素"就默认可以自由传播——传统纹样本身属于公共文化资源，但**特定摄影作品、数字化成果的著作权是独立的**。

### 3. 文化尊重

壮锦是国家级非物质文化遗产，承载壮族文化语义。公开打包传播需要慎重——**不是不能做，而是应该在有清晰说明和尊重语境的前提下做**。

### 因此本仓库的做法是

| 处理 | 说明 |
| --- | --- |
| 数据集图片 | **不入库**（`dataset/` 已在 `.gitignore` 排除，仅保留占位） |
| 打标文件 | **入库**（`prompts/captions/` — 这是技术资产，不含图像内容） |
| 参考文献 PDF | **不入库**（他人已发表成果，`docs/literature-notes.txt` 保留文献梳理） |
| 数据集说明 | 本文件 |

**要复现训练**，请按第四节自行准备数据。打标规范已完整给出，这是最难复现的部分，其余是流程工作。

## 六、数据集的已知局限

| 局限 | 影响 | 改进方向 |
| --- | --- | --- |
| **规模小**（训练集 18 张量级） | 风格表达受限，偏保守 | 扩充到 100+ 张 |
| **与推理输入同源** | 生成图会保留输入图结构，"创新性"打折 | 构建独立测试集（训练未见过） |
| **打标完全同构** | 无法做细粒度控制（如"只要菱形不要蝶花"） | 改为差异化打标 + 添加属性标签 |
| **单一风格** | 只能生成一种壮锦调性 | 按纹样类型（几何 / 植物 / 动物母题）分组打标 |
| **无标注来源与授权** | 无法追溯每张图的获取途径 | 建立素材台账，记录来源与授权状态 |

> 最后一条最值得补：**建一份数据来源台账**，记录每张图的采集途径、授权状态、是否可商用。这既是学术规范，也是后续商用化的前提。
